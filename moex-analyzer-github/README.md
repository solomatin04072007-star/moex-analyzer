# MOEX Analyzer

Персональный ИИ-анализатор Московской биржи. Анализирует акции и облигации, 
обучает ML-модели для прогноза движения цен, отправляет ежедневные уведомления.

## Возможности

- Технический анализ акций (RSI, MACD, SMA, Bollinger Bands, ATR)
- 758 ML-моделей XGBoost (краткосрочные 5 дней + долгосрочные 20 дней)
- Скрининг облигаций с фильтрами по ликвидности и надежности эмитента
- Портфельный трекер с расчетом P&L и секторной концентрации
- Тепловая карта секторов рынка
- Бэктест стратегии на исторических данных
- Прогноз индекса МОЕХ через ML
- Ежедневные уведомления на email и в Ntfy

## Стек

- Python 3.11
- ML: XGBoost, scikit-learn
- Data: pandas, numpy
- Визуализация: Streamlit, plotly
- API: MOEX ISS
- AI-ассистент: DeepSeek

## Запуск

streamlit run app.py
